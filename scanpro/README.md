# ScanPro — تطبيق مسح المستندات الاحترافي

> **الحالة الحالية: المرحلة الأولى (التحليل) — مكتملة.**
> لم يُكتب أي كود تطبيق بعد. هذه الوثائق هي الأساس الهندسي الذي ستُبنى عليه المراحل التالية، وفق منهجية «لا واجهات وهمية، ولا ادعاء نجاح قبل الاختبار».

## ملاحظة جوهرية عن هذا المستودع

هذا المستودع (`khutwati`) يحتوي تطبيقًا قائمًا غير ذي صلة (تطبيق لياقة عربي مبني على Apache Cordova). مشروع ScanPro:

- **لا يمكن** أن يُبنى فوق بنية Cordova/WebView الحالية — متطلبات الكاميرا ومعالجة الصور وOCR تفرض مشروع React Native أصليًا (وهو ما ينص عليه البرومبت صراحة).
- وُضعت مخرجات المرحلة الأولى في مجلد `scanpro/` مستقل دون المساس بالتطبيق القائم.
- **التوصية:** قبل بدء المرحلة الثانية (تأسيس المشروع)، يُنشأ مستودع Git مستقل لـ ScanPro (أو يُتخذ قرار صريح بأن هذا المستودع سيتحول بالكامل إلى ScanPro). خلط تطبيقين في مستودع واحد سيعقّد CI/CD والنشر وأرقام الإصدارات.

## خلاصة القرارات التقنية (تفصيلها ومسوّغاتها في الوثائق)

- **الأساس:** React Native + Expo (Development Build وليس Expo Go) + TypeScript Strict + Expo Router + Zustand + expo-sqlite (مع FTS5).
- **محرك المسح في MVP:** الماسحات الأصلية للنظامين — VisionKit على iOS وML Kit Document Scanner على Android — لأن جودة المسح هي المنتج الحقيقي، والماسحات الأصلية تعطي اكتشاف حواف وتصحيح منظور بجودة إنتاجية من اليوم الأول. الكاميرا المخصصة الكاملة (react-native-vision-camera + معالجة أصلية) مرحلة لاحقة مدروسة.
- **OCR:** Apple Vision على iOS (يدعم العربية من iOS 16). **تحذير جوهري:** ML Kit على Android لا يدعم العربية — هذه أكبر مخاطرة تقنية في المشروع، والبدائل مفصلة في وثيقة المخاطر.
- **PDF:** توليد PDF بالصور + طبقة نص خفية عبر `pdf-lib` (JS خالص)، مع نقل التشفير وكلمات المرور إلى وحدة أصلية في مرحلة لاحقة لأن pdf-lib لا يدعم التشفير.
- **الاشتراكات:** RevenueCat فوق StoreKit 2 وGoogle Play Billing.
- **الخصوصية:** كل شيء محلي افتراضيًا؛ لا رفع تلقائي؛ المفاتيح في Keychain/Keystore عبر SecureStore.

## ما الذي لن تجده هنا عمدًا

- لا كود UI ولا شاشات — البرومبت يحدد أن المرحلة الأولى تحليل فقط، والمرحلة الثانية هي تأسيس المشروع.
- لا ادعاءات جاهزية لأي ميزة — كل ميزة ستُعلن مكتملة فقط بعد اختبارها فعليًا على iOS وAndroid.
