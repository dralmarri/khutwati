# 7. قصص المستخدم ومعايير القبول — النسخة 1.0

كل قصة لها معايير قبول قابلة للاختبار. القصص الموسومة **[E2E]** تدخل في رحلات Maestro الآلية؛ البقية تُختبر بـ unit/integration + فحص يدوي موثق.

## أ. الإعداد الأول واللغة

**US-01 — أول تشغيل** [E2E]
كمستخدم جديد، أرى صفحات تعريفية مختصرة ثم أصل للشاشة الرئيسية دون إنشاء حساب.
- ✓ أربع صفحات تعريف قابلة للتخطي.
- ✓ لا يُطلب أي إذن أثناء الـ Onboarding.
- ✓ لا توجد شاشة تسجيل دخول في التطبيق كله.
- ✓ لغة أول تشغيل تتبع لغة الجهاز (عربي ⇒ RTL كامل).

**US-02 — تبديل اللغة**
كمستخدم، أبدّل بين العربية والإنجليزية من الإعدادات.
- ✓ التبديل يقلب الاتجاه RTL/LTR بعد إعادة تشغيل معلنة برسالة واضحة.
- ✓ لا نص hardcoded: فحص آلي (lint) يفشل عند وجود نص حرفي في مكوّن.
- ✓ شاشات المستند والبحث تعرض خليط عربي/لاتيني/أرقام دون تشوه BiDi (فحص بصري موثق).

## ب. المسح

**US-03 — مسح متعدد الصفحات** [E2E]
كمستخدم، أضغط زر المسح فتُفتح الكاميرا، تكتشف حدود الورقة، وألتقط عدة صفحات.
- ✓ إذن الكاميرا يُطلب عند أول ضغط على «مسح» فقط، مع شرح السبب.
- ✓ رفض الإذن ⇒ شاشة حالة توضح كيفية التفعيل من الإعدادات (لا انهيار ولا طريق مسدود).
- ✓ كشف الحواف والتقاط تلقائي ويدوي وفلاش متاحة (عبر الماسح الأصلي).
- ✓ 10 صفحات متتالية على جهاز Android بـ 3GB دون انهيار.

**US-04 — مسودة لا تضيع** [E2E]
كمستخدم، إذا أُغلق التطبيق أثناء المسح أستعيد صفحاتي.
- ✓ كل صورة ملتقطة تُحفظ فورًا (قرص + DB) قبل أي معالجة.
- ✓ عند إعادة الفتح يُعرض خيار استكمال المسودة أو حذفها.

**US-05 — تعديل الحدود يدويًا** [E2E]
كمستخدم، أعدّل زوايا أي صفحة بعد الالتقاط.
- ✓ أربع مقابض قابلة للسحب + عدسة تكبير عند السحب.
- ✓ «قص تلقائي» و«الصورة كاملة» و«إعادة الضبط» تعمل.
- ✓ إعادة القص تعيد المعالجة من الصورة الأصلية دائمًا (لا فقدان جودة تراكمي).
- ✓ تصحيح المنظور ينتج صفحة مستطيلة من التقاط مائل ≤ 30°.

**US-06 — الفلاتر**
كمستخدم، أطبّق فلترًا على صفحة أو على كل الصفحات مع معاينة قبل التأكيد.
- ✓ الفلاتر الستة (أصلي/تلقائي/ملون/أبيض-أسود/رمادي/تحسين نص) تعمل.
- ✓ المعاينة تظهر قبل التطبيق؛ المعالجة في الخلفية بمؤشر تقدم؛ الواجهة لا تتجمد.
- ✓ الأصل لا يُستبدل أبدًا.

**US-07 — إدارة الصفحات** [E2E]
كمستخدم، أُعيد ترتيب الصفحات بالسحب وأحذف وأدوّر وأضيف صفحات.
- ✓ سحب وإفلات بترقيم محدث فوريًا.
- ✓ حذف صفحة مع تراجع (Undo) خلال الجلسة.
- ✓ إضافة صفحات من الكاميرا ومن المعرض إلى مستند قائم.

**US-08 — استيراد**
كمستخدم، أستورد صورًا أو PDF وأحوّلها لمستند.
- ✓ إذن الصور يُطلب عند أول استيراد فقط.
- ✓ استيراد PDF يعرض صفحاته ويُدرجه كمستند.
- ✓ «مشاركة إلى ScanPro» من تطبيقات أخرى تعمل على النظامين.

## ج. الحفظ وPDF

**US-09 — حفظ مستند** [E2E]
كمستخدم، أحفظ المسح باسم (عربي أو إنجليزي) في مجلد.
- ✓ اسم افتراضي مقترح (نوع + تاريخ) قابل للتعديل.
- ✓ أسماء عربية بالكامل تعمل في الحفظ والعرض والبحث والمشاركة (الملف الفعلي UUID).

**US-10 — إنشاء PDF** [E2E]
كمستخدم، أُصدّر مستندي PDF بحجم صفحة وجودة أختارهما.
- ✓ A4 وLetter وتلقائي؛ رأسي وأفقي؛ ثلاث درجات جودة.
- ✓ الحجم المتوقع يظهر قبل الحفظ بدقة ±15%.
- ✓ الملف الناتج يفتح سليمًا في Adobe Reader وApple Files وGoogle Drive.
- ✓ ملف 50 صفحة يُولَّد دون انهيار وبمؤشر تقدم وقابلية إلغاء.

## د. OCR والبحث

**US-11 — استخراج النص** [E2E]
كمستخدم، أستخرج نص مستندي وأعدّله وأنسخه.
- ✓ iOS: عربي وإنجليزي عبر Vision. Android: إنجليزي عبر ML Kit وعربي عبر Tesseract مع تنبيه جودة صريح.
- ✓ النص يظهر بجانب الصفحة، قابل للتعديل والنسخ والمشاركة والحفظ TXT.
- ✓ متوسط الثقة معروض، والكلمات منخفضة الثقة مميزة بصريًا.
- ✓ تنبيه ثابت: «النص المستخرج قد يحتوي أخطاء — راجع المستندات المهمة».
- ✓ الكلمات غير الواضحة لا تُستكمل تخمينًا (سلوك المحرك يُحترم، لا post-processing توليدي).

**US-12 — PDF قابل للبحث** [E2E]
كمستخدم، أُصدّر PDF يمكن البحث داخله ونسخ نصه.
- ✓ طبقة نص خفية بمواضع الكلمات الصحيحة (اختبار: بحث ونسخ في قارئ خارجي يعيدان النص الصحيح في الموضع الصحيح).

**US-13 — البحث الشامل** [E2E]
كمستخدم، أبحث فأجد مستنداتي بالاسم أو الوسم أو نص داخلها.
- ✓ البحث يشمل: الاسم، الوسوم، الملاحظات، نص OCR.
- ✓ «فاتوره» تجد «فاتورة»، و«احمد» تجد «أحمد» (التطبيع العربي).
- ✓ نتائج < 500ms مع 1000 مستند (بيانات اختبار مولدة في بيئة التطوير فقط — لا بيانات وهمية في الإنتاج).
- ✓ فلاتر: النوع، المفضلة، المجلد، التاريخ.

## هـ. التنظيم

**US-14 — مجلدات ومفضلة وسلة** [E2E]
كمستخدم، أنظّم مستنداتي وأستعيد ما حذفته.
- ✓ إنشاء/إعادة تسمية/حذف مجلد (لون وأيقونة).
- ✓ نقل مستند، تحديد متعدد، إضافة للمفضلة، وسوم.
- ✓ الحذف ينقل للسلة؛ الاستعادة ترجع المستند بمجلده ووسومه؛ الحذف النهائي بعد 30 يومًا أو يدويًا بتأكيد صريح.

**US-15 — إدارة التخزين**
كمستخدم، أرى ما يستهلك المساحة وأنظّفه.
- ✓ أحجام مفصلة: مستندات، أصول، PDF، مؤقتات، سلة.
- ✓ تنظيف المؤقتات وتفريغ السلة بتأكيد.
- ✓ حذف الصور الأصلية خيار بتحذير صريح يشرح فقدان إمكانية إعادة القص.
- ✓ لا حذف لأي شيء دون تأكيد.

## و. الأمان

**US-16 — قفل التطبيق** [E2E]
كمستخدم، أقفل التطبيق بالبصمة/الوجه أو PIN.
- ✓ التفعيل يتطلب نجاح مصادقة أولى + تعيين PIN احتياطي.
- ✓ لا محتوى يظهر قبل فك القفل (يشمل العودة من الخلفية بعد مدة القفل التلقائي المختارة).
- ✓ معاينة App Switcher محجوبة على النظامين.
- ✓ فشل البيومترية ⇒ مسار PIN؛ لا طريق مسدود.

**US-17 — خصوصية قابلة للتحقق**
كمستخدم، بياناتي لا تغادر جهازي.
- ✓ صفر طلبات شبكة أثناء رحلة المسح الكاملة (يُتحقق منه بمراقبة الشبكة في اختبار موثق).
- ✓ لا صور ولا نصوص OCR في السجلات أو تقارير الأعطال (فحص Sentry scrubbing).
- ✓ «حذف جميع البيانات» يمسح DB والملفات والمفاتيح ويعيد التطبيق لحالة أول تشغيل.

## ز. معايير عرضية (تنطبق على كل الشاشات)

- ✓ لكل شاشة: حالة تحميل، خطأ (مع إعادة محاولة حيث يمكن)، فراغ، وفقدان صلاحية.
- ✓ الوضع الداكن كامل بلا نصوص غير مقروءة.
- ✓ VoiceOver/TalkBack: كل الأزرار التفاعلية موسومة؛ أهداف لمس ≥ 44pt.
- ✓ تكبير الخط حتى أكبر إعداد نظام دون قصّ نصوص في الشاشات الرئيسية.
- ✓ رحلة §38 كاملة (16 بندًا) تمر على iPhone حديث وiPhone صغير وAndroid منخفض المواصفات قبل إعلان 1.0.
