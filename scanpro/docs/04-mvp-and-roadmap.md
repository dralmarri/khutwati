# 4. الـ MVP الواقعي وخطة المراحل

## 4.1 نطاق النسخة الأولى (1.0) — قابلة للنشر فعليًا

مطابق لتعريف الاكتمال في §38 من المتطلبات، ومبني على مبدأ «جودة محرك المسح هي المنتج»:

**داخل 1.0:**
1. Onboarding مختصر + طلب أذونات عند الحاجة فقط.
2. مسح متعدد الصفحات عبر الماسح الأصلي (VisionKit / ML Kit Scanner): كشف حواف، تصحيح منظور، التقاط تلقائي ويدوي، فلاش.
3. استيراد من معرض الصور وملفات PDF.
4. شاشة قص/زوايا يدوية بإعادة معالجة من الأصل + تدوير.
5. فلاتر: أصلي، تلقائي، أبيض/أسود، تدرج رمادي، تحسين نص، ملون.
6. إدارة صفحات: ترتيب بالسحب، حذف، تدوير، إعادة قص، إضافة صفحات.
7. حفظ مستند + مجلدات (مستوى واحد في 1.0) + مفضلة + إعادة تسمية.
8. PDF: أحجام A4/Letter/تلقائي، جودة/ضغط، ميتاداتا أساسية، معاينة الحجم المتوقع.
9. OCR محلي: عربي+إنجليزي على iOS (Vision)، إنجليزي (ML Kit) وعربي (Tesseract مع تنبيه جودة) على Android + PDF قابل للبحث + عرض/تعديل/نسخ النص + مؤشر الثقة.
10. بحث: الاسم والوسوم ونص OCR عبر FTS5 مع تطبيع عربي.
11. مشاركة/تصدير/طباعة عبر Share Sheet الأصلية.
12. سلة محذوفات (30 يومًا) + إدارة تخزين أساسية (أحجام + تنظيف مؤقتات + تفريغ السلة).
13. قفل التطبيق بالبيومترية/PIN + إخفاء المعاينة في App Switcher.
14. عربية/إنجليزية كاملتان + RTL + وضع داكن + حالات فراغ/خطأ/تحميل لكل شاشة.
15. استخدام كامل دون حساب — لا شاشة تسجيل أصلًا في 1.0.
16. مسودة تلقائية تستعيد جلسة المسح بعد إغلاق التطبيق.

**مؤجل عمدًا (مع سببه):**

| الميزة | إلى | السبب |
|---|---|---|
| كاميرا مخصصة كاملة + التقاط تلقائي خاص | 1.2+ | خ-2؛ الأصلية أعلى جودة الآن |
| توقيع وحواشٍ وRedaction | 1.1–1.2 | Redaction يتطلب هندسة دقيقة (خ-4)؛ يُشحن كاملًا أو لا يُشحن |
| حماية PDF بكلمة مرور | 1.2 | لا حل Android جاهز (خ-3) |
| قفل مستند محدد + SQLCipher | 1.2 | يُبنيان معًا (خ-6) |
| مزامنة سحابية + حساب | 2.0 | أكبر مصدر تعقيد وأخطار خصوصية؛ بلا قيمة قبل ثبوت جودة المسح |
| اشتراكات/Paywall | 1.1 | يلزم أولًا منتج يستحق الدفع؛ RevenueCat يجعل الإضافة سريعة |
| أوضاع بطاقة الهوية/الكتاب/السبورة | 1.1–1.3 | وضع «مستند» و«إيصال» (فلتر) يغطيان 80% من الاستخدام |
| مجلدات متداخلة وذكية | 1.1 | مستوى واحد كافٍ لبداية التنظيم |
| OCR سحابي اختياري | 2.0 | يتطلب بنية موافقة وخادمًا |

## 4.2 خطة المراحل (مطابقة لهيكل §37 مع نطاق مضبوط)

| المرحلة | المحتوى | معيار الخروج (لا انتقال قبله) |
|---|---|---|
| **1. التحليل** | هذه الوثائق | مراجعة واعتماد القرارات — **أنت هنا** |
| **2. التأسيس** | مشروع Expo Dev Build + TS strict + Router + الثيم + i18n/RTL + SQLite/migrations + Zustand + نظام أخطاء/سجلات + ESLint/Prettier + CI للبناء + اختبارات أساسية | يبنى ويعمل على iOS+Android فعليًا؛ تبديل اللغة والاتجاه والوضع الداكن يعمل؛ `npm test` أخضر |
| **3. المسح الأساسي** | وحدة `scanpro-scanner` الأصلية + وحدة `scanpro-image` (منظور/فلاتر/thumbnails) + شاشة القص اليدوي + إدارة الصفحات + المسودات + الاستيراد | رحلة: مسح 10 صفحات → تعديل → فلترة → حفظ، على جهازين حقيقيين دون انهيار |
| **4. المستندات وPDF** | pdf-lib + شاشة الحفظ + القوائم والمجلدات والمفضلة + بحث بالاسم + سلة المحذوفات + مشاركة/طباعة + إدارة التخزين | PDF مُصدَّر يفتح في Adobe/Files/Drive بأحجام صفحات صحيحة؛ حذف واستعادة موثوقان |
| **5. OCR** | وحدة `scanpro-ocr` (ثلاثة مزودات) + طبقة النص في PDF + شاشة النص والتعديل + FTS5 مع التطبيع العربي + مؤشرات الثقة | نص عربي وإنجليزي يُستخرج ويُبحث فيه؛ PDF قابل للبحث يثبت ذلك في قارئ خارجي |
| **6. القفل والصقل** | البيومترية/PIN + `scanpro-privacy` + إمكانية الوصول (VoiceOver/TalkBack) + حالات الخطأ الشاملة (§28) + أداء (خ-5) | قائمة §38 كاملة تمر يدويًا + Maestro E2E أخضر على النظامين |
| **7. النشر 1.0** | أيقونات/Splash/بيانات المتاجر بالعربية والإنجليزية/Privacy Labels/Data Safety/سياسة خصوصية/بيئات Dev-Staging-Prod | قبول App Store وGoogle Play |
| **8. ما بعد 1.0** | 1.1: اشتراكات + توقيع/تحرير + أوضاع مسح إضافية ← 1.2: Redaction + تشفير + قفل مستند + كاميرا مخصصة ← 2.0: حساب + مزامنة + OCR سحابي | كل إصدار له معايير قبوله عند التخطيط له |

قاعدة عامة بعد كل مرحلة (من §37): عرض ما نُفّذ، قائمة الملفات، بناء ناجح، صفر أخطاء TypeScript/Lint، اختبار فعلي على iOS وAndroid.

## 4.3 ما الذي يحدد النجاح

مقياس النجاح الوحيد للنسخة 1.0: مستخدم عربي يمسح عقدًا من 5 صفحات في إضاءة مكتب عادية، يحصل على PDF نظيف قابل للبحث، ويجده غدًا بالبحث عن كلمة داخله — دون انهيار ودون حساب ودون إنترنت.
